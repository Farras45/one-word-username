One word, one username, one reward — this entry sends the entrant's own make.fun username, `byron-allen`, and nothing else.

## Run it

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `byron-allen` (11 characters, no trailing newline) to `out/entry.txt`.
